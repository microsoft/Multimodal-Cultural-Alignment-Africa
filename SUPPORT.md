# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs, feature requests, and
documentation improvements. Search existing issues before opening a new one to
avoid duplicates.

For usage questions, open a GitHub issue with:

- the repository commit;
- Python and operating-system versions;
- the command and configuration used;
- a minimal synthetic input that reproduces the problem; and
- relevant error output with credentials and personal data removed.

Do not use GitHub Issues to report security vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.

## Microsoft Support Policy

Support for this project is limited to the community resources described
above. This project is not covered by a Microsoft Customer Service and Support
agreement or service-level agreement.
