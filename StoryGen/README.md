# StoryGen

This directory is reserved for the public story and image generation pipeline
that produces inputs for cultural-alignment evaluation.

The implementation is not included yet. A reproducible release should document:

- prompt and persona schemas;
- model names and versioned deployments;
- generation parameters and random seeds where supported;
- text-to-image pairing rules;
- output conversion to `examples/sample_stories.json` format; and
- data rights, consent, and de-identification requirements.
