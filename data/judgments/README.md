# De-identified judgment data

This directory contains the public, de-identified evaluation records associated
with the project. It includes human cultural-alignment annotations and the
multi-agent LLM judgments from evaluation run 1.

## Coverage

| Language/community | Stories | Human judgments | Anonymous annotators | LLM judgments |
|---|---:|---:|---:|---:|
| Hausa | 40 | 120 | 3 | 40 |
| isiXhosa | 40 | 120 | 3 | 40 |
| Kikuyu | 39 | 195 | 5 | 39 |
| Luo | 40 | 280 | 7 | 40 |
| Xichangana | 40 | 160 | 4 | 40 |

One incomplete Xichangana annotation record containing no meaningful judgments
was excluded. Exact machine-readable counts are in `manifest.json`.

## Files

Each language directory contains:

- `human_annotations.jsonl`: evaluated stories, multimodal references, and
  anonymous human judgments.
- `llm_judgments.jsonl`: the corresponding multi-agent LLM scores, rationales,
  cultural markers, and debate metadata.

The `story_id` field aligns the human and LLM files. IDs are language-local and
do not preserve the raw task or study identifiers.

`SHA256SUMS` contains hashes for the JSONL files and manifest.

## Human annotation schema

Each line contains:

- language, country, culture, and story metadata;
- story text, paragraphs, local image paths, image/audio counts, and question;
- experimental condition, generation model, and story arc;
- `human_annotations`, grouped by anonymous `annotator_id`;
- cultural score, connectedness judgments, global feedback, text spans,
  image-region annotations, comments, and justifications.

Anonymous annotator IDs are stable only within a language release. No mapping
to names, email addresses, or internal user IDs is retained.

## LLM judgment schema

Each line contains:

- the same anonymous `story_id`;
- the same anonymous local `image_paths`;
- evaluated story, culture, question, category, and task type;
- final score, bracket, reasoning, and text/image cultural markers;
- configuration, consensus status, initial/final agent scores, and debate
  transcript.

Participant profile objects are not included.

## De-identification

The release was generated by `scripts/sanitize_research_data.py`. It:

1. Replaces raw story IDs with sequential language-local IDs.
2. Replaces annotator identities with sequential anonymous IDs.
3. Removes names, email addresses, user IDs, submission IDs, study IDs,
   timestamps, participant profile objects, HTML profiles, prompts, search
   queries, and external media URLs containing raw story identifiers.
4. Renames available downloaded images to anonymous story-based filenames and
   records their repository-relative paths in both aligned judgment files.
5. Replaces every full participant name and name component observed in a
   language source with `Participant` throughout released stories, comments,
   rationales, markers, and debate transcripts.
6. Replaces source profile values such as age, location, religion, occupation,
   dietary restrictions, disability, and health details with
   `[REDACTED_PROFILE_ATTRIBUTE]` throughout free text.
7. Excludes annotator records with meaningful judgments for fewer than half of
   the language's stories.

The release references 809 local images. One image for `hausa_story_025` was
already absent from Supabase when the media archive was created, so that record
retains its original `image_count` of five while listing the four available
local paths.

The raw annotation exports and participant profiles are not distributed.

## Reproduction

Authorized maintainers with access to the private sources can regenerate the
release from the repository root:

```bash
python scripts/sanitize_research_data.py \
    --human-dir /path/to/private/human-exports \
    --llm-dir /path/to/private/llm-run \
    --output-dir data/judgments \
    --image-dir data/images
```

Do not copy raw exports into this repository.

## Responsible use

The released stories may still contain culturally or medically sensitive
generated content even after source profile values are redacted. Do not attempt
to re-identify participants or annotators. Human review is required before
using the content for medical guidance or participant-facing applications.
